# Command-Line Interface (`cli/`)

Unified Typer CLI (`lapa`) that connects all four phases:

| Phase | Commands |
| --- | --- |
| **Phase 1 (`phase1_acquire`)** | `lapa keygen`, `lapa acquire`, `lapa verify`, `lapa show` |
| **Phase 2 (`phase2_parse`)** | `lapa parse`, `lapa verify-derived`, `lapa sql` |
| **Phase 3 (`phase3_analyze`)** | `lapa analyze` |
| **Phase 4 (`phase4_detect`)** | `lapa detect`, `lapa evaluate`, `lapa report` |
